# My Mini Farm

My Mini Farm is a small farming game for Windows. Plant seeds, water your crops, wait for them to grow, harvest them, and sell your harvest.

## How to run

1. Download `Terragame.exe` from the Releases or Downloads section.
2. If it comes in a ZIP file, extract the ZIP first.
3. Double-click `Terragame.exe` to start the game.

The game is provided as a Windows executable, so Python does not need to be installed.
